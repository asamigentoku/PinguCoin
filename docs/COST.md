# 本番(Azure)の月額コストの想定

`platform/terraform/envs/production` の既定値(コスト最小の構成)で、24 時間 365 日動かしたときの想定です。

> **これは概算です。** Azure の料金を実際に確認した値ではなく、リージョン(Japan East)や為替で変わります。構築する前に、[Azure の料金計算ツール](https://azure.microsoft.com/ja-jp/pricing/calculator/)で見積もり、構築後は Azure の **コスト管理(Cost Management)** で、実際の請求を確認してください。
> 為替は、1 ドル = 150 円で換算しています。

## 合計

| | 月額 |
| --- | --- |
| **中央値の想定** | **約 145 ドル(約 2.2 万円)** |
| 想定の幅 | 約 130〜170 ドル(約 2.0〜2.6 万円) |

幅は、Blob Storage の保存量とアクセス数、外へ出る通信の量、為替・料金の変動によるものです。

## 内訳

| 項目 | 構成 | 月額(ドル) | 備考 |

| ノードの OS ディスク | 128 GB(AKS の既定) | 約 20 | `os_disk_size_gb` を小さくすると下がる |

### 含まれていないもの

- **Web アプリ**(`apps/client-web` / `admin-web`)のホスティング(Vercel など)。
- **Clerk**(認証)、**Let's Encrypt**(無料)以外の外部サービス。
- **独自ドメイン**の登録・DNS の費用。
- **GitHub Actions**(プライベートリポジトリの無料枠を超えた分)。
- サポートプラン。

## 無料枠・割引が使えるかもしれないもの

| | 内容 | 効果の目安 |
| --- | --- | --- |
| Azure の新規アカウントの無料枠 | 12 か月、PostgreSQL `B1ms` が月 750 時間、ストレージ 32 GB まで | DB の約 20 ドルが、ほぼ 0 に |
| 新規アカウントのクレジット | 登録から 30 日間 | 最初の月の支払いを相殺 |
| 1 年の予約(Reserved Instance) | ノードと DB に適用 | 約 3 割安く |

対象になるかは、Azure のポータルで確認してください。

## さらに下げる方法

| 方法 | 効果 | 注意 |
| --- | --- | --- |
| OS ディスクを小さくする(`os_disk_size_gb = 64`) | 数ドル | |
| 使わない時間は止める(`az aks stop`、`az postgres flexible-server stop`) | ノードの料金(約 70 ドル)が、止めた時間の分だけ減る | PostgreSQL は最大 7 日で、自動で起動する。止めている間はサービスが使えない。検証中心の間に向いている |
| ノードを `Standard_B2s`(4 GiB)にする | 約 35 ドル | 3 つの API とシステムの Pod が載る、ぎりぎりのメモリ。不足すると、Pod が再起動を繰り返す |

## 構成を上げたときの増え方

DB は、方針として最安のまま(上げない)です。

| 変更 | 増える額(ドル/月) |
| --- | --- |
| AKS を Standard tier(SLA あり) | 約 73 |
| ノードを 3 つにする | 約 140(ノード 2 つ分と、ディスク) |
| 両方 | 約 210〜220(合計で約 360 ドル) |

## 費用を見張る

- **予算のアラート**: Azure の「コスト管理 > 予算」で、月の上限(例: 200 ドル)を作り、80% と 100% でメールが届くようにする。
- **タグで絞る**: すべてのリソースに `environment = production` のタグを付けています。コスト管理で、このタグで絞ると、本番だけの費用が見られます。
- 構成の変更は、`platform/terraform/envs/production` と [DEPLOYMENT.md](DEPLOYMENT.md) を参照してください。
